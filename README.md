# 自动小说盒子

本地网页版长篇小说创作助手：一句话开篇 → 分部/分章逐步生成 → 支持重写、下一章、抽打、回退与手动编辑。所有数据保存在本地 `data/` 目录。

## 环境要求

- Node.js ≥ 20（自带 npm）
- 一个 OpenAI 兼容的 API（自建服务或第三方均可）：需要 Base URL、模型名与 API Key

## 一键启动

- macOS：双击 `启动.command`（首次运行若被 Gatekeeper 拦截，右键 → 打开 → 允许）
- Windows：双击 `启动.bat`

脚本会自动完成：安装根依赖 → 若无 `web/dist` 则构建前端 → 检查 4399 端口 → 启动服务 → 打开浏览器到 `http://localhost:4399`。
如果 4399 已被占用，脚本只会提示占用 PID 并退出，不会自动结束其它进程。

也可以手动运行：

```bash
npm install
npm run build   # 构建前端 → web/dist
npm start       # 启动服务，监听 4399（可用 PORT 覆盖）
```

## 首次使用

1. 打开浏览器进入 `http://localhost:4399`。
2. 在「API 设置」中填入 Base URL、模型名、API Key，保存。Key 在展示时会被掩码。
3. 在首屏输入一句话开篇（比如「一个失忆的少年在废墟里捡到会说话的猫」），点「开始 ✍️」。创建后进入全书大纲页，点「🔄 重写」生成大纲，大纲会流式逐字出现。
4. 点「新建部」创建第一部，然后点「下一章」生成第 1 章。侧边栏出现 ✓ 表示已生成。
5. 想要重写：点「重写」；想要局部调整：在「抽打」输入意见（如「节奏太慢，开头加冲突」），旧版本会自动进入回退栈。
6. 需要回退：点「↩ 上一版」还原到上一个版本。
7. 也可以手动修改正文，切走再切回内容会保留。

## 数据与备份

- 所有小说数据保存在项目目录下的 `data/`：
  - `data/config.json`：API 设置（Key 会存到本地）
  - `data/books/<bookId>/`：每本书一个目录
    - `book.json`：全书大纲/设定/人物/部列表
    - `section-XX/section.json` + `chapter-XX.json`：分部与章节
- 备份：直接复制 `data/` 目录即可。删除某本书直接删除对应的 `books/<bookId>/` 目录。

## 常见问题

- 服务启动失败：检查 4399 端口是否被占用。macOS/Linux 可通过 `PORT=5001 npm start` 换端口；Windows 可通过 `set PORT=5001 && npm start` 换端口。
- 生成没反应：进入 API 设置检查 Base URL、模型名、Key 是否正确；日志会打印在启动脚本的终端窗口里。
- 生成的 JSON 报错：`extractDigest` 会自动尝试兜底，若仍失败，本次 digest 不会阻塞正文保存，可稍后再抽打一下重试。
