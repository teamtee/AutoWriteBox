# 上下文指导语 A/B 盲读记录

本表用于比较同一模型、同一策划、同一前情下的两种提示词组织方式。候选顺序已经随机打乱；阅读者不应查看 `*-summary.json` 中的 `blindMapping`，只读取 `*-blind-packet.txt`。

## 评判原则

- 不根据“是否完全照策划卡逐项执行”投票；先判断它是否像一章自然发生的小说。
- 不因某章打斗更多、篇幅更长就自动判优。
- 重点观察重复控制是否导致安全文本：篇幅收缩、段落同构、密度均匀、关键动作概述化、人物说话同声。
- 连续性、知识边界和后台标签泄漏属于正确性问题，出现即单列，不与文风偏好混在一起。
- 首轮读完全部候选前不要查看组别映射或确定性统计。
