# 章节审稿闭环 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 章节生成后自动生成审稿卡（评分、问题、建议），用户可一键抽打重写。

**Architecture:** 后端在 `gen/chapter` 正文保存后追加 nonStreamChat 审稿，解析成功写入 `chapter.review`；新增手动审稿路由。前端新增 `ChapterReviewCard` 组件，在章节视图正文下方展示，建议按钮直接触发 `whip` 模式重写。

**Tech Stack:** Node.js ESM + Express, React 18 + TypeScript, Vitest

## Global Constraints

- 审稿失败不阻塞正文保存和 digest。
- 审稿数据不进版本链，只存 `chapter.review` 最新一次。
- 建议按钮复用现有 `/api/gen/chapter mode=whip` 流程。
- 不引入新的 LLM provider 配置。
