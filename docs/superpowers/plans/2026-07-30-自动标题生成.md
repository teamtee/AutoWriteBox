# 书名/部名/章名自动生成 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 全书大纲完成后自动生成书名、每部首个完成章节后自动生成部名、每章正文完成后自动生成章名；AI 只替换默认标题，界面固定显示中文序号前缀。

**Architecture:** 后端为书/部/章增加 `titleSource` 并对老数据惰性迁移；章名和部名复用现有 digest JSON，书名在大纲完成后使用一次短非流式请求。前端只保存纯标题，统一通过 `titles.ts` 格式化成“第一部 · 标题”“第一章 · 标题”。

**Tech Stack:** Node.js ESM + Express + `node:test`；React 18 + TypeScript strict + Vitest + Vite。

## Global Constraints

- 不新增 npm 依赖。
- AI 标题最多 10 个 Unicode 字符，只保存纯标题，不保存《》、引号、序号前缀或解释。
- AI 只允许覆盖 `titleSource === "default"` 的标题；`manual` 和 `ai` 均不可被后续生成覆盖。
- 书名：大纲完成后生成；部名：该部首个成功完成正文的章节后生成；章名：每章正文完成后生成。
- 标题生成与解析属于非关键路径；失败不得回滚正文、大纲、摘要或把成功的 SSE 变为 error。
- 部/章序号由前端根据 `index` 生成：`第一部 · 标题`、`第一章 · 标题`；默认标题为空时只显示 `第一部`、`第一章`。
- 老数据迁移优先保护用户数据：无法确认来源的非默认标题一律视为 `manual`。
- 后端全量验证：`node --test server/test/*.test.js`，0 fail、0 skip。
- 前端全量验证：`cd web && npm test`、`npm run build`；`tsc -b` 零错误。
- 当前工作区含上一轮已验证但未提交的启动脚本、旧数据容错和 VersionedBox 尺寸改动。执行本计划前必须先把它们按原功能单独提交，不能混入自动标题提交。

```js
const TITLE_SOURCES = new Set(['default', 'ai', 'manual']);
const CN_NUM = '零一二三四五六七八九十百千两';

function normalizeEntityTitle(entity, unit) {
  if (TITLE_SOURCES.has(entity.titleSource)) return entity;
  const raw = typeof entity.title === 'string' ? entity.title.trim() : '';
  const ordinal = `第\\s*(?:\\d+|[${CN_NUM}]+)\\s*${unit}`;
  const onlyOrdinal = new RegExp(`^${ordinal}$`);
  const withPrefix = new RegExp(`^${ordinal}\\s*[·:：\\-—]?\\s*(.*)$`);
  if (!raw || onlyOrdinal.test(raw)) {
    entity.title = '';
    entity.titleSource = 'default';
    return entity;
  }
  const m = raw.match(withPrefix);
  entity.title = (m ? m[1] : raw).trim();
  entity.titleSource = 'manual';
  return entity;
}

function migrateBookTitleInPlace(book) {
  if (!TITLE_SOURCES.has(book.titleSource)) {
    const fallback = (book.premise ?? '').slice(0, 20);
    book.titleSource = book.title === fallback ? 'default' : 'manual';
  }
  return book;
}
```

```js
export function sanitizeGeneratedTitle(raw, unit = '') {
  let text = String(raw ?? '').split(/\r?\n/, 1)[0].trim();
  text = text.replace(/^[《“”"'「」『』]+|[》“”"'「」『』]+$/g, '').trim();
  text = text.replace(/^(?:书名|章名|部名)\s*[:：]\s*/u, '').trim();
  if (unit) {
    const ordinal = new RegExp(
      `^第\\s*(?:\\d+|[零一二三四五六七八九十百千两]+)\\s*${unit}\\s*[·:：\\-—]?\\s*`, 'u');
    text = text.replace(ordinal, '');
  }
  text = text.replace(/^[《“”"'「」『』]+|[》“”"'「」『』]+$/g, '').trim();
  text = text.replace(/^[·:：\-—\s]+/u, '').trim();
  return Array.from(text).slice(0, 10).join('');
}
```

扩展 `extractDigest`：

```js
export function extractDigest(text) {
  const fallback = {
    chapterTitle: '', sectionTitle: '',
    summary: '', progress: '', newCharacters: [],
  };
  const tryParse = (s) => { try { return JSON.parse(s); } catch { return null; } };
  let obj = tryParse(text.trim());
  if (!obj) {
    const m = text.match(/\{[\s\S]*\}/);
    if (m) obj = tryParse(m[0]);
  }
  if (!obj) return fallback;
  return {
    chapterTitle: sanitizeGeneratedTitle(obj.chapterTitle, '章'),
    sectionTitle: sanitizeGeneratedTitle(obj.sectionTitle, '部'),
    summary: obj.summary || '',
    progress: obj.progress || '',
    newCharacters: Array.isArray(obj.newCharacters) ? obj.newCharacters : [],
  };
}
```

```ts
const DIGITS = ['零', '一', '二', '三', '四', '五', '六', '七', '八', '九'];
const UNITS = ['', '十', '百'];

export function toChineseNumber(n: number): string {
  if (!Number.isInteger(n) || n < 0 || n > 999) return String(n);
  if (n === 0) return DIGITS[0];
  let out = '';
  let pendingZero = false;
  for (let pos = 2; pos >= 0; pos--) {
    const power = 10 ** pos;
    const digit = Math.floor(n / power) % 10;
    if (digit === 0) {
      if (out && n % power !== 0) pendingZero = true;
      continue;
    }
    if (pendingZero) {
      out += DIGITS[0];
      pendingZero = false;
    }
    if (!(pos === 1 && digit === 1 && out === '')) out += DIGITS[digit];
    out += UNITS[pos];
  }
  return out;
}

export function formatIndexedTitle(
  index: number,
  unit: '部' | '章',
  title = '',
): string {
  const prefix = `第${toChineseNumber(index)}${unit}`;
  const clean = title.trim();
  return clean ? `${prefix} · ${clean}` : prefix;
}
```
