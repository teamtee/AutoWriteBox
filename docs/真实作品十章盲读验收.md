## 验收原则

正式验收必须由未参与策划和生成的人，在不知道大纲、提示词、模型评分与作者解释的情况下连续阅读。每章只记录第一次阅读反应，不把“知道作者以后会解释”当作正文已经成立。

每章记录以下七项：

1. **开章 300 字牵引**：此刻具体想知道什么；若没有，记录第一次想跳读的位置。
2. **人物依恋**：关心谁，原因来自哪个动作、选择、关系或代价；设定介绍不算。
3. **主角主动性**：主角本章想完成什么、亲自做了什么、承担了什么后果。
4. **新信息与有效兑现**：本章改变了什么；重复解释旧结论不算新信息。
5. **阻力可信度**：前文承诺的困难是否真正发生；门槛无原因消失视为负兑现。
6. **章末自然追读**：不看下一章标题，是否愿意立刻点击；只记“愿意 / 犹豫 / 不愿意”及唯一主因。
7. **十分钟后记忆点**：能复述的人物选择、画面或问题；只能记住术语不算人物与剧情成立。

十章结束后只统计三类结果：在哪一章首次犹豫、在哪一章首次不愿继续、最想追的一个人物或问题。模型评分只可作为改稿线索，不能替代这三项人工结论。

## 编辑预读：赛博朋克稿第 1–4 章

### 第一章

- **有效内容**：妹妹只剩 7.3% 生命体征使救援目标具体；妹妹十二岁爬电视塔的细节是少数真正建立关系的内容；“意识农场”有清楚题材承诺。
- **主要摩擦**：匿名档案、老周地图、研究员录像、艾薇员工卡连续把答案送到主角手里。信息很多，但主角尚未靠自己的黑客能力赢下一次局面。
- **表达问题**：血色霓虹、死萤火虫、钢钉般眼睛、利剑般高塔等比喻过密，重要信息和装饰争夺注意力。
- **章末承诺**：天亮前潜入高安保 S-07 并到妹妹病床前。第二章必须兑现“如何进去”和“妹妹在哪里”，不能直接跳过。

### 第二章

- **首要弃读风险**：第一句“铁门没有锁”直接削弱第一章已经建立的“铁幕防火墙、十二台无人机和生物识别锁”。困难没有被人物能力解决，而是无原因消失。
- **主角被动**：艾薇刷卡、带路并解释八千万意识节点、液氮、量子计算和意识覆写；林深主要负责提问、震惊和握拳。
- **负兑现**：第一章说要到妹妹病床前，本章却参观陌生舱体后直接去控制室，没有找到妹妹，也没有为偏离目标付代价。
- **章末钩子**：神秘弹窗知道“蝶蛹”和陈玄机父亲，问题本身有效；但它建立在全程几乎没有巡逻、无人机或安保反击的轻松潜入上。

### 第三章

- **阻力继续缺席**：弹窗明确说总部已经知道入侵，主角二人仍能离开控制室、寻找承重柱、读取照片和大量文件，没有倒计时、追兵、封锁或取舍。
- **信息替代行动**：本章的主要变化来自陈远山录像和实验文本，而不是林深破解、欺骗或承担代价。
- **连续性矛盾**：弹窗称“半年前被宣布病逝的父亲”，录像又明确陈远山十三年前已被媒体宣布死亡；正文随后再次称“半年前被宣布病逝的天穹创始人”。
- **重复结论**：意识矩阵、活体算力和“零”的信息与前两章同属一组揭密，升级靠扩大数字而非人物选择。

### 第四章

- **格式问题**：正文内混入“# 第四章”，与前三章及应用标题体系不一致。
- **重复揭密**：陈远山再次解释自己创造零、被儿子上传和意识矩阵；第三章刚揭开的核心信息没有先变成行动或后果。
- **主角功能**：林深仍以提问、理解和宣誓为主。艾薇与陈远山负责工具、路线和答案，黑客身份没有形成可反复期待的核心行动。
- **有效钩子**：格式塔协议与“去深渊找零”给出下一站，但连续四章都在追加更大秘密，读者尚未获得一次由主角亲手完成的有效兑现。

### 四章总判断

题材承诺清楚，但阅读循环目前是“进入地点 → 向导讲解 → 发现更大秘密 → 宣布下一站”。真正需要建立的循环应是“林深用黑客能力解决一道有反制的门槛 → 为接近妹妹付出可见代价 → 拿到一部分真相或救援进展 → 天穹针对他的做法升级”。

优先改稿顺序：

1. 让第二章的高安保真正发生：员工卡只能过第一层，林深必须破解或欺骗系统，并因选择留下可追踪痕迹。
2. 兑现“到妹妹病床前”：即使救不走，也必须确认她的具体状态、得到一次个人回应或因救援失败失去某样东西。
3. 把第二至第四章的三轮说明压成一次，腾出篇幅给巡逻、反制、选择和后果。
4. 修正陈远山“半年前 / 十三年前”矛盾；明确半年前发生的到底是信号消失、第二次死亡公告还是别的事件。
5. 给艾薇独立欲望和风险，不让她只做门卡、百科与扫描仪。

## 编辑预读：《笼中火种》第一章

### 为什么更值得继续验证

- “十二个火种”“存活率 80% / 100 年”和现实失业者形成快速题材承诺。
- 狼崽、老人挡在洞口、火烧黑石部落把选择与代价写成了具体场景，不依赖旁白宣布沉重。
- 系统把战争评价为 S、屏外观众馈赠能量，和陆沉的道德反应形成差异化体验。
- 结尾现实死伤 312 人对应棋盘内死亡，使“游戏是否映射现实”成为足够明确的追读问题。

### 当前最大风险

- **第一章烧掉太多故事**：狩猎、狼袭、五年生活、六年干旱、三百人火攻、再度围困、十七年终局、重开和现实映射全部集中在 4840 字内。最有价值的道德变化被大量时间跳跃挤压。
- **时间线错误**：写完“第六年，干旱”后又出现“第二年，黑石部落残部……”，与前后十七年终局无法顺读。
- **数量可信度不足**：黑石部落先写七十多人，随后同一轮围山变成三百名猎人；若是联盟或聚集，应在现场给出来源。
- **比喻密度偏高**：刀子、铁钉、油花、琴弦、面包、花瓣、校对、冷铁、火线、手掌等连续出现，部分有力，部分稀释场景本身。
- **主角初始欲望偏弱**：失业和祖父棋盒只是身份背景。陆沉为何选择“进入”而不是旁观，尚缺一个能贯穿现实与棋盘的个人需求。

### 建议的十章展开方式

不必机械按以下章数切割，但应把关键选择还给场景：

1. 进入棋盘、认识十二个人、第一次狩猎；结尾猎人因他的“策应”重伤或死亡。
2. 狼崽引来狼群；陆沉第一次决定牺牲谁，明确系统观众的存在。
3. 处理死者、驯养狼崽、资源增长；现实端出现第一处无法解释的对应。
4. 干旱与水源危机；先接触黑石部落，不直接跳到战争。
5. 谈判失败或被背叛；陆沉必须在九人与对方平民之间作选择。
6. 火攻及其即时后果；系统给出 S 评价，陆沉第一次试图退出。
7. 黑石残部联合反扑；此前选择造成具体报复。
8. 暗河与短暂希望；人物关系和部落内部对陆沉产生分裂。
9. 火种终局；让熟悉的人逐个完成选择，而不是用摘要报死亡数字。
10. 继承记忆重开，并揭示现实 312 人映射，形成第一个大阶段翻面。

这一本应作为正式十章盲读的优先样本。目标不是把第一章简单切成十份，而是为每次选择补足欲望、阻力、行动、转折与代价，并让现实线逐章产生可验证的回声。
