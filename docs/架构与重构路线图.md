## 下一阶段

### P1：前端控制器

1. 抽出书架加载、建书、导入、删除和恢复控制器。
2. 抽出章节懒加载、保存、草稿保护和版本冲突控制器。
3. 抽出生成与审稿的 state/ref 双写互斥注册表，保持停止后磁盘核对语义。
4. 引入浏览器交互测试后覆盖组件卸载、快速切章和双击操作。

### P2：API 领域模块

保持 `api.ts` 为统一门面，内部按 books、config、assets、memory 等领域迁移。普通 JSON 和 SSE 必须继续复用同一公开错误合同，组件导入路径不变。

### P3：大型解析器

拆分 `backup-json.js` 前先固化：

- 重复键、非法 UTF-8、尾随损坏和大小边界；
- 流式投影不物化完整大对象；
- 随机访问索引与既有备份字节格式兼容。

## 每次拆分的验收条件

1. 对外导出、HTTP 错误码和持久化格式保持兼容。
2. 服务端全量测试通过。
3. 前端类型检查、全量测试和生产构建通过。
4. 快速/深度存储诊断保持只读，事务恢复和取消语义不变。
5. `git diff --check` 与架构门禁通过。
6. 不通过压缩、删注释或复制逻辑规避行数门禁。
