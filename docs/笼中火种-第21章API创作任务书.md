# 《笼中火种》第 21 章 API 创作任务书

## 本章读者体验

读者应先获得一次扎实确认：陆沉确实改变了新的现实结果，而且沙盘没有因他离开而停止。随后，确认感要被更大的不安替代——映射不是简单复制，棋盒不只一个观察席，保留众人已经活过的三日会让陆沉失去原来的玩家特权。

本章不是现实调查报告，也不是世界观说明章。核心动作是：陆沉先建立核对表，再尝试错误方案，最后把陌生薄片嵌入祖父棋盒，亲手打开一个有代价的入口。

## 张力曲线

后脑疼痛、观察断线与新闻信息不足先形成低位压迫；预写四项事实后逐项吻合，给读者第一次确定感；未受损桥立刻打破“逐物复制”的简单答案。断网和物理遮挡一度让陆沉以为可以控制风险，定位回执不受影响再度反制。看见沙盘已经自行运行三日，是本章最大的情绪释放；两个入口随后把释放变成选择压力。至少呈现两次有因果的强弱变化，不能从头到尾只维持紧张，也不能靠突然响铃或连续系统弹窗制造假起伏。

## 场景骨架

1. 陆沉从地板爬起，先把自己在看新闻前已经知道的四项事实写在纸上，防止事后挑相似处。
2. 新闻逐项对应：提前一小时撤离、三座营地、泄洪方向、零伤亡；但现实多出一座未受损桥。陆沉原先假设“逐物复制”，当场被修正。
3. 他在相同外部时间附近发现另一条规模较小、自己完全没有沙盘记忆可对应的异常冲突。只产生疑问：也许不是只有一个观察区。
4. 棋盒原九点矩阵关闭。手机、断网、物理遮挡等尝试都不能让薄片停止回执；陆沉意识到对方定位的是沙盘观察通道，不只是现实网络。
5. 薄片严丝合缝嵌入盒内一处长期被当作锈斑的缺口。这个物证只暗示祖父棋盒曾预留第二部件，不解释祖父。
6. 第二通道打开，陆沉看见沙盘已经过去三日：芽在第三道日痕旁数人，众人正在自行重建。
7. 出现两个入口。恢复快照会覆盖这三日；陌生入口保留当前线，却使陆沉成为未登记单位，失去数值视野、任务奖励和安全退出。
8. 结尾停在他手指悬于两个入口之间。不要替下一章做选择。

## 四层埋点

- 近期回收：现实零伤亡的细节对应，回答第 20 章的结果是否有效。
- 中期悬念：第二观察通道会留下定位回执，另一观察者此后能更准确找到薪火区域。
- 长线物证：祖父棋盒预留第二薄片的位置，暗示他留下的不是偶然捡到的单件装置。
- 世界规模：一条陆沉无法对应的异常冲突，暗示可能存在别的沙盘或观察区；本章不给答案。

## 写作 trick

- 采用“先写预测、再核新闻”的方法，让证据可信，不让主角只挑有利相似处。
- 采用“一处不吻合”扩大世界：未受损桥不是漏洞解释，而是告诉读者现实仍有独立变量。
- 一个物件承担三种功能：薄片既是空的任务证据、第二通道钥匙，也是对手定位陆沉的反向信标。
- 每回答一个问题，只新增两个更大的问题，保持冰山感；禁止一次性给专有名词百科。
- 宏观感来自“还有别的事件无法对应”和“时间线可被覆盖”，不来自空喊宇宙、高维或全人类。
- 让陆沉的理性体现为具体操作与自我防偏差，不用旁白夸他冷静聪明。

## 人物与语言

- 本章限知陆沉，现实中不新增承担讲解功能的人物。
- 陆沉刚经历强制离场，身体有后脑疼痛与掌心烫痕，但不能长时间自怜。
- 系统文字短、冷、只给选项与代价；陌生白字更像一个有所有权意识的人，但不说谜语式空话。

## 禁止项

- 不让现实 312 人伤亡撤销或下降。
- 不让新闻直接提到游戏、沙盘、观察者或外星文明。
- 不让陆沉靠断网就切断高层通道，也不写黑客攻防。
- 不解释祖父身份、NPC本体、牧场真相或另一观察者真名。
- 不用连续屏幕信息和内心总结撑满一章；必须有书写、核对、拆盒、试错、嵌入等动作。
- 不把“宏大世界观”误写成密集名词、神秘人自说自话或突兀宇宙镜头。
