# HTTP 路由索引

所有路由只依赖 `../store.js` 公共门面。

- `config.js`：当前 API 配置、多方案、模型发现与单书绑定。
- `books.js`：作品、部章、版本、承诺账本、人物导演卡、单章/黄金三章审稿、分项修订候选、发布、记忆和连载设置。
- `gen.js`：大纲、分部规划、章节策划候选、章节生成、摘要与自动审稿；策划候选走可取消 JSON 请求，其余长正文走 SSE。
- `assets.js`：创作资产提取、导入、绑定和删除。
- `storage.js`：诊断、备份传输、导入导出和临时文件生命周期。

路由负责 HTTP 校验、状态映射、流背压和客户端取消传播；领域一致性、锁和落盘事务属于 store。
